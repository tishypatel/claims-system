Part 04
Deployment Challenges

Deploying to QBE Dev Env

⚠️
Database — lowdb vs Enterprise DB
Currently uses a flat JSON file (lowdb). QBE dev environment likely runs Oracle or PostgreSQL. Migration layer needed — schema maps cleanly, but connection string, ORM, and migration scripts must be added.
🔑
Authentication — SSO / LDAP Integration
Current auth uses hardcoded demo users. QBE dev env will require LDAP or SAML SSO integration (Active Directory). The auth middleware is isolated and can be swapped without touching the rest of the app.
🌐
Network Proxy & CORS Policy
Vite's /api proxy is a dev-only config. In QBE's environment, a reverse proxy (nginx / Apache) or API gateway needs to be configured. CORS headers on the Express server must list QBE's internal domain.
🔐
Secrets Management — API Keys
The Anthropic API key is in a .env file. QBE's dev environment should use a vault (HashiCorp Vault / AWS Secrets Manager). The key must never be committed to internal SCM or exposed in build artifacts.
📦
Node.js Version & Package Registry
Requires Node ≥ 18 (ESM imports). Corporate npm registries may block public registry access — an .npmrc pointing to QBE's Nexus/Artifactory would be needed for all packages including Vite and Anthropic SDK.
✅
What Works Out of the Box
The React build produces static files (npm run build → dist/) that can be served by any web server. The Express API is containerisable with a single Dockerfile. No OS-specific native binaries in the production bundle.
Part 04
Deployment Roadmap

Path to Production

1
Swap Database Layer Week 1

Replace lowdb with pg (PostgreSQL) or oracledb. The data schema is already clean — one file change in database.js + add migration scripts.

2
Auth Integration Week 1–2

Wire Passport.js SAML or LDAP strategy into the existing auth middleware. The role-based access control logic is already in place — just needs real user lookup.

3
Containerise + Configure Week 2

Write Dockerfile for backend, configure nginx to serve React static files and proxy /api. Update .npmrc for internal package registry.

4
Secrets + CI/CD Week 3

Move ANTHROPIC_API_KEY to QBE's vault, configure CI pipeline (Jenkins / GitHub Actions) for build → test → deploy on merge to main.
